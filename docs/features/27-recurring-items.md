# 27 — Recurring items

Status: Draft · Milestone: — · Priority: Later
Depends on: 06, 08

## Goal
Regular work (weekly 1:1s, monthly board update) appears automatically.

## Scope
**In**
- Recurrence rule on tasks and notes: daily, weekly (weekday), monthly (day of month), every N weeks.
- Next instance created when the current one is completed (or on its date).
- Quick-add: `every:mon`, `every:2w`, `every:month`.

## Acceptance criteria
- [ ] Completing a weekly task creates the next week's one with the same fields.
