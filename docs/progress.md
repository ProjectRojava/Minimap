- [x] 24 Demo data (implemented; manual click-through pending). - [x] 25 Undo (implemented; manual click-through pending). Ctrl/Cmd+Z undoes and Ctrl/Cmd+Shift+Z redoes the last change this session (20 steps, also in the palette), built from the activity log with no schema change: one command is one step, creates are archived rather than deleted, a step is refused (writing nothing) if something changed since, and deletes, attachments and link details are steps that say they can't be undone. Notes keep their editor's own undo.
- [x] 26 Full data export (implemented; manual click-through pending). Settings → Data & backup → Export writes a new timestamped folder (built as .part, never overwrites) with one JSON file per kind of item, every link, the full history, archived items, a manifest, a README and the attached files that are on this computer; optionally Markdown (a file per project with its tasks, the inbox, each note). The demo data round-trips through the files into the same structs. No import (decision in the spec).
- [x] 27 Recurring items (implemented; manual click-through pending). Demo data, export and undo cover it.
