# Keyboard shortcuts

Minimap is built to be used without the mouse. Shortcuts that are single keys work when you are **not typing in a text box**; `Ctrl/Cmd+K` works everywhere. (`Cmd` on a Mac, `Ctrl` elsewhere.)

## Anywhere

| Keys | Does |
|---|---|
| `Ctrl/Cmd+K` | Open the command palette ([Quick-add and the palette](help:quick-add)) |
| `/` | Jump to the search box ([Search](help:search)) |
| `?` or `F1` | Open this help |
| `Ctrl/Cmd+Z` | Undo the last change ([Undo and redo](help:undo)) |
| `Ctrl/Cmd+Shift+Z` or `Ctrl+Y` | Redo |
| `Esc` | Close the detail pane, or leave a text box |
| `Ctrl/Cmd+S` | Make a save point: a copy of everything, with a name if you like ([Backup and restore](help:backup-restore)) |
| `Ctrl/Cmd+Shift+M` | Open or close the [radar](help:radar), the small always-on-top window |
| `v` | Switch between Portfolio view and My view ([Portfolio view and My view](help:views)) |
| `Alt+↑` | Zoom out one level: from a task to its project, objective and the Overview ([Zoom](help:zoom)) |
| `Alt+↓` | Zoom back in to where you came from, or into the highlighted row |

Inside a text box `Ctrl/Cmd+Z` undoes the typing, as usual, and `Alt+↑` / `Alt+↓` do not zoom.

## On the Gantt screen

Click the chart first. `↑` `↓` move between rows (`Home`, `End`, `PageUp`, `PageDown` jump), `→` `←` open and fold them, `*` opens every project, `t` brings today into view, `Enter` opens the row's date box, `Alt+←` `Alt+→` move the open task (or a project's or objective's target) one working day and `Alt+Shift+←` `Alt+Shift+→` move only a task's end or a project's start. `Esc` closes the date box or cancels a drag. `Ctrl/Cmd+F` finds a row by name (then `Enter` and `Shift+Enter` step through the matches) and `Ctrl` with the mouse wheel zooms. The same keys work in the Table view. See [Gantt](help:gantt).

## In lists

| Keys | Does |
|---|---|
| `j` / `k` | Move down / up the rows |
| `Enter` | Open the highlighted row in the detail pane |
| `n` | New item, on screens that have a "new" box or form (Tasks, Projects, Notes and so on). On the task board it opens the box in the To do column |

### On the highlighted task row or card (Tasks, board and list, and Inbox; `x`, `f` and `c` also on This week; `m` on every list)

| Keys | Does |
|---|---|
| `x` | Mark done; again to reopen |
| `s` | Move to the next status |
| `f` | Put in focus, or take out of focus ([Tasks](help:tasks), *Focus*) |
| `b` | Put on the backburner, or bring it back ([Tasks](help:tasks), *The backburner*). Tasks, board and list |
| `m` | Leave a [ping](help:pings) on it: a box asks for a day and a note. Works on any list, the board and This week. On a row of This week's Pings card, `x` clears the ping |
| `c` | Say it is still accurate: clears its fog without changing it ([Fog](help:fog)). Also on projects, objectives, This week and the weekly review's Fog step |
| `1`–`5` | Set the priority |
| `d` | Focus the due date (list only) |
| `a` | Focus the assignee (list only) |

## In other places

| Where | Keys |
|---|---|
| Command palette | `↑`/`↓` choose, `Enter` run, `Esc` close |
| Search results | `↑`/`↓` choose, `Enter` open, `Esc` clear |
| `@` picker in a note | `↑`/`↓` choose, `Enter` or `Tab` insert, `Esc` cancel |
| Weekly review | `n` next step, `p` previous step, `j`/`k`/`Enter` rows |
| Drop-down lists | `Enter`/`Space`/`↓` open, arrows move, `Enter` choose, `Esc` close, `Home`/`End` first/last |
| Dependency graph | Drag to pan, wheel to zoom |

## Typing dates

Wherever a date is asked for you can type `YYYY-MM-DD`, or in quick-add and on [This week](help:this-week) words such as `fri`, `next-wed`, `+3d`.
